# 💙 Ramo de Hot Wheels

Página web romántica y responsive inspirada en un ramo de flores con carritos Hot Wheels.

## Características

- Animación de entrada: "Tengo algo para ti..."
- Ramo que se construye por etapas.
- Flores azules con apertura animada.
- Carritos con entrada lateral y movimiento.
- Luna, estrellas, brillo y partículas.
- Corazones flotantes.
- Efecto 3D/parallax con mouse.
- Soporte para orientación del teléfono.
- Diseño responsive para celular, tablet y PC.
- Respeta `prefers-reduced-motion`.
- No necesita servidor, base de datos ni dependencias externas.

## Ejecutarlo

Abre `index.html` directamente en el navegador.

## Publicarlo gratis con GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `ramo-hot-wheels`.
2. Sube `index.html`.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub Pages publique el sitio.
7. GitHub te dará una dirección parecida a:

`https://TU-USUARIO.github.io/ramo-hot-wheels/`

Esa es la liga que puedes mandar por WhatsApp, Instagram, Messenger, etc.

## Personalizar

En `index.html` puedes cambiar:

- El título principal.
- El mensaje romántico.
- El texto del bloque de código.
- Los colores de las flores.
- Los colores de los carritos.
- El número de flores.
- La velocidad de las animaciones.

## Nota

Los carritos están dibujados con HTML/CSS para que el proyecto sea autónomo y fácil de subir a GitHub Pages. No utiliza imágenes externas.
